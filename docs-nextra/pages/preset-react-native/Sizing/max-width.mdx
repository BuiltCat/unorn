title: Max Width
---

 `max-width`属性用于设置元素的最大宽度。

## 基本使用

使用`max-w-{size}`设置元素的`maxWidth`。


```typescript
'max-w-0' -> { maxWidth: 0 }
'max-w-0.5' -> { maxWidth: 0.5 }
'max-w-1/2' -> { maxWidth: '50%' }
```


## 自定义

### 自定义主题

默认情况下，该预设只会提供一组基本的主题设置。你可以通过以下方式进行自定义主题。

`maxWidth`可以使用`spacing`中的设置，也可以使用`maxWidth`中的设置。


1. 使用`spacing`进行设置。

> 设置
```diff lang="javascript"
{
    theme: {
+        spacing: {
+           'base': 1
+        },
    }
}
```
> 使用
```diff lang="javascript"
'max-w-base' -> { maxWidth: 1 }
```

2. 使用`maxWidth`进行设置。
> 设置
```diff lang="javascript"
{
    theme: {
+        maxWidth: {
+           'xl': 5
+        },
    }
}
```
> 使用
```diff lang="javascript"
'max-w-xl' -> { maxWidth: 5 }
```

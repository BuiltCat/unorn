---
title: User Select
---

 `userSelect`允许用户选择文本并使用本机的复制和粘贴功能。

## 基本使用

使用`select-none | select-text | select-all | select-auto | select-contain`设置元素的`userSelect`。


```typescript
'select-none' ->  { userSelect: 'none' }
'select-text' ->  { userSelect: 'text' }
'select-all' ->  { userSelect: 'all' }
'select-auto' ->  { userSelect: 'auto' }
'select-contain' ->  { userSelect: 'contain' }
```

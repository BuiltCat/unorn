 `pointerEvents`用来设置元素是否可以成为触摸事件的目标。

## 基本使用

使用`pointer-events-none | pointer-events-auto | pointer-events-box-none | pointer-events-box-only`设置元素的`pointerEvents`。


```typescript
'pointer-events-none' ->  { pointerEvents: 'none' }
'pointer-events-auto' ->  { pointerEvents: 'auto' }
'pointer-events-box-none' ->  { pointerEvents: 'box-none' }
'pointer-events-box-only' ->  { pointerEvents: 'box-only' }
```

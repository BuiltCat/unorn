 `fontStyle`控制元素的样式。

## 基本使用

使用`italic` | `not-italic`设置元素的`fontStyle`。


```typescript
'italic' -> { fontStyle: 'italic' }
'not-italic' -> { fontStyle: 'normal' }
```

 `min-width`属性用于设置元素的最小宽度。

## 基本使用

使用`min-w-{size}`设置元素的`minWidth`。


```typescript
'min-w-0' -> { minWidth: 0 }
'min-w-0.5' -> { minWidth: 0.5 }
'min-w-1/2' -> { minWidth: '50%' }
```


## 自定义

### 自定义主题

默认情况下，该预设只会提供一组基本的主题设置。你可以通过以下方式进行自定义主题。

`minWidth`可以使用`spacing`中的设置，也可以使用`minWidth`中的设置。


1. 使用`spacing`进行设置。

> 设置
```diff lang="javascript"
{
    theme: {
+        spacing: {
+           'base': 1
+        },
    }
}
```
> 使用
```diff lang="javascript"
'min-w-base' -> { minWidth: 1 }
```

2. 使用`minWidth`进行设置。
> 设置
```diff lang="javascript"
{
    theme: {
+        minWidth: {
+           'xl': 5
+        },
    }
}
```
> 使用
```diff lang="javascript"
'min-w-xl' -> { minWidth: 5 }
```
